## 最终生成约束 / 提示词

使用内置 image_gen 工具，透明 RGBA 输出。每张均采用网站参考，日系手绘 Q 版、奶油粉彩、低对比柔和阴影、暖色细线与粗白贴纸边；避免扁平 emoji、塑料 3D、强镜面高光和复杂背景。全套鸡蛋无眼睛、嘴巴、脸或表情。

1. **好鸡蛋：** 一个完整圆润的奶金色哑光鸡蛋，健康完好蛋壳、洁净暖色、细微笔触，无手脚、皇冠和文字。
2. **坏鸡蛋：** 一个浅灰绿鸡蛋、几条轻微裂纹、稀疏淡斑点，清爽不恶心，无虫、臭气或液体。第一次生成带草窝，最终用图像编辑只移除草窝，使两枚投票图构图一致。
3. **吃过：** 两半完全空的奶油白蛋壳与绿色对勾；按用户反馈单独提高对勾绿色，使用约 #55945C、#7CAE73 高光、#416D48 轮廓，保留蛋壳与布局。
4. **没吃过：** 一个完整奶油白蛋放在暖浅棕小柳编篮子，黑色小蝴蝶结呼应已有网站篮子；小尺寸可辨。
5. **Eku：** 重新生成，保持 pending 的坐姿、一手拿放大镜、另一手在下巴旁思考；恰好两手且各自连着独立袖子，裂纹蛋独立在草窝中，无手碰蛋。浅金长发、猫耳猫尾、正常粉眼、黑波浪发箍、两个黑小发夹和丝带。黑高领短裙、灰白短外套及灰色纹样袖口/翻领、白长袜、黑玛丽珍鞋。无黑军装、链条、红领饰或侦探帽。最初第三只手版本及改变手部动作的版本均未采用。

## 转换

`scripts/prepare-interaction-assets.cjs` 使用 Sharp 将选定 PNG 复制为源交付物，并以 quality 86、alphaQuality 100、effort 6 生成 WebP。调用参数为 `name=PNG绝对路径`；需要 Node 和 Sharp。转换只做尺寸与格式优化，不修画面内容。
